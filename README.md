# Personal Portfolio Website

Portofolio web modern yang menampilkan berbagai proyek Software & AI Development. Dibuat dengan tampilan interaktif, responsif, serta dilengkapi fitur *Dark/Light Mode* dan efek kursor *spotlight*.

## Fitur Utama

- **Dynamic Typewriter**: Animasi teks ketik otomatis di bagian Hero Section.
- **Interactive Cursor Spotlight**: Efek sorotan lampu menyala (*glowing*) yang mengikuti arah kursor mouse.
- **Filter Proyek**: Fitur penyaringan proyek interaktif berdasarkan kategori.
- **Dark / Light Theme Toggle**: Pengubah tema tampilan terang dan gelap.
- **Fully Responsive**: Tampilan rapi di layar HP maupun komputer.

## Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Custom Variables, Flexbox, Grid)
- **JavaScript (ES6+)**
- **Lucide Icons**
